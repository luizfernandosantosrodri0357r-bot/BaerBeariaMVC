# 💈 BaerBeariaMVC - Projeto Final

Sistema de gerenciamento para Barbearia desenvolvido em ASP.NET Core MVC.

## 🚀 Funcionalidades
- Cadastro de Barbeiros
- Cadastro de Clientes
- Agendamento de Serviços
- Controle de Serviços e Preços
- Gerenciamento de Horários

## 🛠️ Tecnologias
- C# / ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML / CSS / Bootstrap

## ▶️ Como rodar o projeto
1. Abra o arquivo `BaerBeariaMVC.slnx` no Visual Studio
2. Restaure os pacotes NuGet
3. Configure a string de conexão no `appsettings.json`
4. Rode o projeto com F5
